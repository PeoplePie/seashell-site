# Seashell

The site at http://sportseashell.com: Seashell, a 30 mm shell that takes the call, in development at TU Delft
(Pau Adell and William Roskaer). Static pages (GitHub Pages from `main`) and the Supabase schema for the waitlist and
page-view counts (`supabase/migrations/`, applied by the GitHub integration). `js/config.js` holds the publishable key,
which is public by design; row-level security on the tables lets the browser only insert. Contact: contact@sportseashell.com.
